# Rob's Blog

A personal blog where I think out loud — about ideas, reasoning, technology, and whatever I can't stop reading about.

**[blog-roberto-reale.vercel.app](https://blog-roberto-reale.vercel.app)**

---

I write to understand things, not to explain things I already understand. Most posts start from a question I couldn't answer cleanly. The format is Q&A-driven: instead of essay prose, I break each piece into the questions that actually structure the thinking.

Topics drift, but the thread is the same: first principles, critical thinking, honest uncertainty, and trying to say something that holds up under scrutiny.

---

Built with Astro 4, Tailwind CSS, MDX, and TypeScript. Deployed on Vercel.
